Effort S/M/L; numbered with `node scripts/backlog-next.js P`, never reusing a closed item's number.

Last reviewed: 2026-11-21 · Transcripts read up to: 2026-11-21T15:33:52Z.

- **Watching**: applied, with the command that measures it, its baseline and its target. The next run re-measures: target met → remove the item; missed → move it to Open with what was learned.
- **Open**: recommended, not yet picked.
- **Declined**: with the user's reason. Not proposed again unless new evidence contradicts the reason.

## Setup review

- Facts: `npm run check:doc-refs` (stale script names, flags, npm scripts and links in skills and CLAUDE.md) · `npm run check:setup` (skill frontmatter, allows covering an ask-first action; a `settings.local.json` warning is a finding too) · `node scripts/setup-facts.js` (each script's callers, and which read arguments without a usage line: one taking only optional flags may not need one) · `node scripts/setup-facts.js --cost` (~2–3 min: the gates' time, output and peak load, ⚠ past 25% slower — a **Cost** finding, and any doc quoting that time is stale; blocked commits; [backlog-run](../../.claude/skills/backlog-run/SKILL.md)'s review yield per phase, a phase low over 3+ runs being a **Cost** finding; CLAUDE.md's size and the largest docs)
- Evals: `node scripts/skill-evals.js --repeat=3 [--dry-run] [skill]` ([testing.md](testing.md#skill-evals); `--ref=HEAD` for before) · Lint: `scripts/setup-lint.js` · Gate: `node scripts/e2e\.js|npm run check` · Numbering: `node scripts/backlog-next.js P`
- Out of scope: app code ([code-audit](../../.claude/skills/code-audit/SKILL.md)), dependencies ([dependency-audit](../../.claude/skills/dependency-audit/SKILL.md)). Not findings: `HISTORY` in `scripts/doc-refs.js`. A `scripts/` change gets a Development changelog entry and a test.
